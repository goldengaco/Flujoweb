🌐 1. Arquitectura API-Led Connectivity (3 Capas) Patrón Oficial de Integración
CAPA 1 · EXPERIENCE API 📱 exp-mobile-orders-api Adapta el formato para la app móvil o frontend web. Quita datos innecesarios y aplica rate-limiting.
CAPA 2 · PROCESS API ⚙️ proc-order-fulfillment-api Orquesta la lógica de negocio pura: calcula descuentos, valida inventario y coordina pagos.
CAPA 3 · SYSTEM API 🗄️ sys-sap-erp-api & sys-db-api Desacopla los sistemas difíciles (SAP S/4HANA, AS400, Oracle DB). Si SAP cambia, nada arriba se rompe.
