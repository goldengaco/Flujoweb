## 🚀 Portal Maestro Central (Launchpad)

El punto de entrada principal del ecosistema es el **Launchpad Central** (`sistemas/index.html`), que permite buscar, filtrar y lanzar cualquiera de los 21 sistemas con telemetría en vivo y visor de documentación.

```bash

start sistemas/index.html
```

## 🌟 Características de Ingeniería

- **100% Autocontenido**: Cero dependencias externas de librerías o frameworks. Todo construido con HTML5 semántico, CSS3 moderno (Grid, Flexbox, Variables, `clamp()`) y Vanilla JavaScript.
- **Cero Sobreposiciones Visuales**: Diseño probado en resoluciones desde 360px (smartphones ultra-compactos) hasta 3840px (monitores 4K).
- **Física y Animaciones a 60 FPS**: Motores de partículas Canvas 2D, trazados de Electrocardiograma (ECG) en tiempo real y flujos vectoriales de paquetes.
- **Sintetizadores de Audio Web**: Sirenas de alarma procesadas con Web Audio API y sintetizador de voz en español con Web Speech API.
